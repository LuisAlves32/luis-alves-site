# Luis Alves REALTOR®

Website of Luis Alves, REALTOR® with Stonehaus Realty Corp. (Greater Vancouver, BC), in English
and Portuguese, including the **Second Opinion** notes.

- Next.js (App Router), React, Tailwind CSS, next-intl, GSAP, Lenis, Motion.
- The notes are written in the Keystatic panel at `/keystatic` and live in `content/notas/`.
- Third-party components and fonts are credited in [CREDITOS.md](CREDITOS.md).

Design and development by Tá Online.
